# FlyRank Capstone — AI-Powered Web App

An AI-powered React web application built during the FlyRank AI Frontend Engineering Internship (2026).

## Overview
This project explores building modern, intelligent frontend experiences using React and the Claude API — focusing on clean UI, real-time AI interaction, and production-ready code patterns.

## Tech Stack
- **Frontend:** React 18, Vite, TailwindCSS
- **AI:** Claude API (claude-sonnet-4-6)
- **Version Control:** Git with Conventional Commits
- **AI Assistant:** Cursor (Composer 2.5)

## Getting Started
npm install
npm run dev
