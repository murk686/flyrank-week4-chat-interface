# Cursor Rules — Project Instructions
## Project
AI-powered web app built with React + Claude API for the FlyRank AI Frontend Engineering internship.
## Stack & Tools

Runtime: Node.js 20 LTS
Frontend: React 18, Vite, TailwindCSS
AI Integration: Anthropic Claude API (claude-sonnet-4-6)
Editor: Cursor IDE (Composer 2.5 Fast)
Commits: Conventional Commits format

## Coding Conventions

Language: JavaScript (ES6+), JSX
File naming: PascalCase for components, camelCase for utilities
No inline styles — use TailwindCSS utility classes only

## AI Guidelines

Prefer clean readable code over clever one-liners
Always include error handling for API calls
Follow existing folder structure when generating components
